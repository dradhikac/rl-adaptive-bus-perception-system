# Reinforcement Learning-Driven Adaptive Perception Reliability and Blind Spot Risk Prediction System

## Goal
Develop an adaptive AI-based autonomous urban bus perception system using:
- Multi-camera vision
- LiDAR fusion
- Reinforcement learning
- Fuzzy intelligence
- Blind spot prediction

## Modules
1. BDD100K Reliability Module
2. nuScenes Sensor Fusion Module
3. Waymo Blind Spot Module
4. KITTI Classical CV Module
5. RL + Fuzzy Intelligence Module
6. Frontend + Deployment Module
